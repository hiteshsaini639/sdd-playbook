# Parked work: the playbook's own

The playbook's own later work. The rules are in
`practices/parked-work.md`. Here, an item is most often a practice that is
still being learned on a project. It moves into `practices/` once it has
been learned the hard way (README → How this grows), and not before.

## Template
```
# W<n> — <title>

Status: todo · Area: <practices | skills | hooks | templates> · Parked: <date> (<who>)

What it is, in two lines.
- What is known so far, one line each.

Earns its place when: <what a project must have seen happen>.
```
