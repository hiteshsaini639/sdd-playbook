# W6 — Action cards in chat

Status: todo · Area: practices · Parked: 2026-11-17 (owner)

In chat, a staff member asks a user to do something in the app: fill in a
form, log something, read a page. The request arrives as a card that opens
the thing, and the card turns Done by itself once the thing is done.
- Requests can be withdrawn, and the user can be reminded.
- The user has a "Waiting for you" list of open requests.
- After each save, the user is offered the next open request.

Earns its place when: it is live and the staff use it in place of plain
messages.
