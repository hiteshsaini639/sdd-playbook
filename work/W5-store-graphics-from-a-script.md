# W5 — Store listing graphics made by a script

Status: todo · Area: practices · Parked: 2026-11-17 (owner)

The app store screenshots are screens captured from a test build and
framed by a script, with a headline in each language. The captures and the
script are committed with the set.
- When a headline changes, run the script again. Nobody redraws the image
  by hand.
- Check the headlines in each language before uploading them.

Earns its place when: a second release has remade the set from the script
rather than by hand.
